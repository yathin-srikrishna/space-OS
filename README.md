Project Overview: A Windows-Compatible Custom Operating System Model

This project demonstrates a custom Operating System (OS) model designed to run efficiently on Windows platforms. The system features a fully integrated File Management System that allows users to seamlessly import, view, and organize digital assets, including photos and music files. 

Key applications and functionalities built into the system include: 

Text Editing:A built-in Notepad application that allows users to compose, edit, and save text documents.
Multimedia Support:A dedicated music module enabling users to import and play their favorite audio tracks.
Personalization:Advanced settings that allow users to customize their user interface, including changing the desktop background theme.
File Sharing & Tracking:Integrated file sharing capabilities alongside real-time date and time stamps for accurate file logging.
Universal Search Bar:An easy-to-use search bar that allows users to quickly look up and open any application they need.
